# Cloudflare ゾーン追加（saunako.jp）— Claude in Chrome 用 指示書

作成日: 2026-09-06
対象: Cloudflare 個人アカウント `e125443b737b2ebdfc1779a7fbd28588`
関連Issue: [#168](https://github.com/teppe049/saunako/issues/168)

## なぜ必要か

Cloudflare の Email Routing（#169）や AI Crawl Control（#170）を使うには、`saunako.jp` の DNS を Cloudflare に移す必要がある。この作業は**ゾーンを追加してレコードを正しく登録するところまで**で、ネームサーバーの切り替えは含まない（切替は反映に最大48時間かかるため、レコード検証後に別途行う）。

ホスティングは Vercel のまま。Cloudflare は DNS を持つだけで、トラフィックは通さない。

## 🔴 絶対に守ること

1. **プロキシは全レコード「DNS only」（グレーの雲）にする。** オレンジの雲にすると Cloudflare がトラフィックを中継してしまい、Vercel の Bot 保護とキャッシュが壊れる。Vercel 公式もプロキシ経由を非推奨としている
2. **TXT レコード（google-site-verification）を必ず登録する。** Search Console が `sc-domain:saunako.jp`（ドメインプロパティ）で登録されており、この TXT で所有権を証明している。欠けると SEO 計測が止まる
3. **ネームサーバーは変更しない。** Cloudflare が「NSを変更してください」と促してくるが、この作業では従わない
4. **アカウントを間違えない。** 同じログインに「株式会社SaunaTrip」アカウントがあり、そちらには本番の Workers・R2・D1 が動いている。触らない

## 登録するレコード（3件）

2026-09-06 に `dig` で実測した現行値。これが唯一の正解で、Cloudflare の自動スキャン結果がこれと違う場合は手で直す。

| # | 種別 | 名前 | 値 | プロキシ |
|---|---|---|---|---|
| 1 | A | `saunako.jp`（またはルート `@`） | `216.198.79.1` | DNS only |
| 2 | CNAME | `www` | `99c955fad7308c84.vercel-dns-017.com` | DNS only |
| 3 | TXT | `saunako.jp`（またはルート `@`） | `google-site-verification=UvqO2r8ln7CWEKtlBhQNcmct5XEs70Pzk4oFAPsEOX8` | 該当なし |

- **MX レコードは存在しない。** 自動スキャンで MX が出てきたら、それは想定外なので登録せず報告する
- AAAA / CAA / DMARC / DKIM もなし
- サブドメイン（mail, stg, dev, api 等）もなし

## Claude in Chrome への指示文（ここから下をそのまま貼る）

```
あなたは Cloudflare のダッシュボードで、ドメイン saunako.jp をゾーンとして追加し、DNSレコードを3件登録する作業をします。
ブラウザには既に Cloudflare にログイン済みです。ログインや2要素認証を求められたら作業を止めて報告してください（認証情報は入力しない）。

## 絶対に守ること
- プロキシ設定は全レコード「DNS only」（グレーの雲）にする。「Proxied」（オレンジの雲）には絶対にしない
- ネームサーバーの変更はしない。Cloudflareが変更を促してきても従わず、そのまま残して報告する
- 作業対象は個人アカウント。「株式会社SaunaTrip」アカウントには一切触らない
- 既存のレコードやゾーンを削除・変更しない。今回追加する3件の作成のみ
- 有料プランへのアップグレードは選ばない。必ずFreeプランを選ぶ
- クレジットカード情報の入力を求められたら、作業を止めて報告する

## 前提
- 対象アカウント: https://dash.cloudflare.com/e125443b737b2ebdfc1779a7fbd28588/home
- 対象ドメイン: saunako.jp
- このドメインの現在のネームサーバーはXserver（ns1.xdomain.ne.jp など）。切り替えは今回やらない

## 手順

### 1. アカウントの確認
https://dash.cloudflare.com/e125443b737b2ebdfc1779a7fbd28588/home を開く。
画面に表示されているアカウント名を報告すること。もし「株式会社SaunaTrip」と表示されていたら、作業を止めて報告する（アカウントを間違えている）。

### 2. ドメインを追加
1. 「Add a domain」または「ドメインを追加」ボタンを押す
2. ドメイン名に saunako.jp を入力する（www は付けない）
3. 「Manually enter DNS records」のような手動オプションと、既存DNSを自動スキャンするオプションが選べる場合は、自動スキャンを選ぶ
4. プラン選択画面が出たら「Free」（無料・$0）を選ぶ。Pro/Business/Enterpriseは選ばない

### 3. スキャン結果の確認
Cloudflareが既存のDNSレコードをスキャンした結果が表示される。
表示された全レコードを、種別・名前・値・プロキシ状態をすべて含めて報告すること。

このとき、以下の3件が正しく入っているか確認する:

| 種別 | 名前 | 値 |
|---|---|---|
| A | saunako.jp（またはルート、@と表示される場合もある） | 216.198.79.1 |
| CNAME | www | 99c955fad7308c84.vercel-dns-017.com |
| TXT | saunako.jp（またはルート、@） | google-site-verification=UvqO2r8ln7CWEKtlBhQNcmct5XEs70Pzk4oFAPsEOX8 |

- 足りないレコードがあれば「Add record」で手動追加する
- 上記3件以外のレコード（特にMXレコード）がスキャン結果に含まれていた場合は、削除も追加もせず、そのまま報告する

### 4. プロキシ設定をすべてDNS onlyにする
AレコードとCNAMEレコードの右側に雲のアイコンがある。
- オレンジ色の雲（Proxied）になっていたら、クリックしてグレーの雲（DNS only）に変える
- TXTレコードには雲のアイコンがない（正常）

**この設定が最重要です。** 変更後、全レコードがグレーの雲になっていることをスクリーンショットで記録する。

### 5. 保存して次へ
「Continue」または「続行」を押す。

### 6. ネームサーバー画面で停止する
次にCloudflareが「ネームサーバーを以下に変更してください」という画面を表示する。
ここで**作業を停止する**。ネームサーバーの変更はこの作業に含まれない。

画面に表示された2つのネームサーバー名（例: xxx.ns.cloudflare.com のような形式）を正確に書き写して報告すること。

### 7. 最終確認
DNS管理画面（https://dash.cloudflare.com/ からsaunako.jpを選び「DNS」タブ）を開き、
登録された全レコードのスクリーンショットを撮る。

## 報告フォーマット
以下の形式で報告してください:

1. アカウント名: （画面に表示されていた名前）
2. ゾーンのステータス: （Pending Nameserver Update など、画面の表示どおり）
3. 選んだプラン: （Free のはず）
4. 登録されたレコード一覧: 種別・名前・値・プロキシ状態を表で
5. TXTレコード（google-site-verification）の有無: あり / なし
6. MXレコードの有無: あり / なし（ありの場合は値も）
7. Cloudflareが指定したネームサーバー: 2つとも正確に
8. スクリーンショット: DNS管理画面
9. 想定外だったこと: あれば何でも

## 途中で止めるべきケース
以下の場合は作業を中断して報告すること:
- ログイン・2要素認証を求められた
- クレジットカード情報の入力を求められた
- アカウント名が「株式会社SaunaTrip」だった
- saunako.jp が既に別のアカウントに登録済みというエラーが出た
- スキャン結果に MXレコードや、上記3件以外の見慣れないレコードがあった
- プロキシをDNS onlyに変更できなかった
```

## 作業後にこちらで検証すること

Claude in Chrome の報告を受けたら、以下をAPIまたは `dig` で検証する。

- [ ] ゾーンが個人アカウント（`e125443b...`）に属している
- [ ] レコード3件が正確に登録されている
- [ ] **全レコードが `proxied: false`（DNS only）である**
- [ ] TXT の google-site-verification が一字一句正しい
- [ ] ネームサーバーはまだXserverのまま（`dig +short NS saunako.jp`）

検証が通ったら、Issue #168 の手順3（ネームサーバー切り替え）に進む。
