# Xserver ネームサーバー切替（saunako.jp → Cloudflare）— Claude in Chrome 用 指示書

作成日: 2026-09-06
関連Issue: [#168](https://github.com/teppe049/saunako/issues/168)
前工程: [Cloudflareゾーン追加](./cloudflare-zone-setup-2026-09-06.md)（完了済み）

## この作業の位置づけ

Cloudflare側のゾーンは準備完了している。2026-09-06 に Cloudflare のネームサーバー（`lola.ns.cloudflare.com`）へ直接問い合わせ、3レコードすべてが期待値と一致することを検証済み。

残るのは**Xserver側でネームサーバーをCloudflareに向ける操作のみ**。これが完了すると、DNSの管理権がXserverからCloudflareへ移る。

## 🔴 この作業のリスク

**これはサイトが引けなくなる可能性がある唯一の危険な操作。** ネームサーバーを間違った値にすると、`www.saunako.jp` が名前解決できなくなりサイトが落ちる。反映に数時間〜24時間かかるため、間違えると復旧にも同じだけ時間がかかる。

そのため、入力値は一字一句正確でなければならない。

## 設定するネームサーバー

Cloudflareが `saunako.jp` に割り当てた専用のネームサーバー。**汎用の `ns1.cloudflare.com` ではない。**

```
lola.ns.cloudflare.com
tadeo.ns.cloudflare.com
```

## 事前確認済みの事実

- **MXレコードは存在しない** → Xserverでメール運用していないため、公式が警告する「移行中のメール受信漏れ」問題は該当しない
- 現行NS: `ns1.xdomain.ne.jp` / `ns2` / `ns3`
- Xserver側のDNSレコード設定は、ネームサーバーを外部に向けても**データ自体は保持される**。「Xserverで利用する」に戻せば復活するため、巻き戻しが可能

## 巻き戻し手順（サイトが落ちた場合）

同じ画面でネームサーバーを以下に戻す。反映にまた数時間かかる。

```
ns1.xdomain.ne.jp
ns2.xdomain.ne.jp
ns3.xdomain.ne.jp
```

## Claude in Chrome への指示文（ここから下をそのまま貼る）

```
あなたはXserverの管理画面で、ドメイン saunako.jp のネームサーバーをCloudflareのものに変更する作業をします。
ブラウザには既にXserverにログイン済みのはずです。ログインや2要素認証を求められたら作業を止めて報告してください（認証情報は入力しない）。

## この作業の重要性
これはサイトが落ちる可能性がある操作です。入力値を1文字でも間違えると www.saunako.jp が名前解決できなくなります。
入力後、確定する前に必ず値を読み上げて確認してください。

## 絶対に守ること
- 設定するネームサーバーは以下の2つだけ。汎用の ns1.cloudflare.com ではありません
    lola.ns.cloudflare.com
    tadeo.ns.cloudflare.com
- 対象ドメインは saunako.jp のみ。他のドメインのネームサーバーは絶対に変更しない
- ドメインの削除・解約・自動更新設定の変更は一切しない
- DNSレコード設定画面のレコードを削除・編集しない
- 「確認画面へ進む」の後、確定前に必ず入力値を報告して確認を取る

## 手順

### 1. 管理画面を開く
https://secure.xserver.ne.jp/xapanel/ を開く。
Xserverアカウントの管理画面です。サーバーパネル（server.xserver.ne.jp）ではありません。

画面に表示されているログインアカウント名を報告してください。

### 2. 対象ドメインを探す
ドメイン一覧から saunako.jp を探す。
一覧に表示されているドメインをすべて報告してください（他のドメインを誤操作しないための確認です）。

### 3. ネームサーバー設定画面へ
saunako.jp の行にあるクイックメニュー、または対象ドメインを選択してから
「ネームサーバー設定」をクリックする。

画面が見つからない場合は、以下も試す:
- 左メニューの「ドメイン」→「ドメイン一覧」→ saunako.jp →「ネームサーバー設定」
- https://www.xdomain.ne.jp/ 側の管理画面

現在設定されているネームサーバーを報告してください。
（ns1.xdomain.ne.jp / ns2.xdomain.ne.jp / ns3.xdomain.ne.jp のはずです）

### 4. 「その他のサービスで利用する」を選ぶ
設定画面には以下のような選択肢があります:
- 「Xserverで利用する」
- 「その他のサービスで利用する」

「その他のサービスで利用する」を選択する。

### 5. ネームサーバーを入力
入力欄に以下を設定する。

ネームサーバー1: lola.ns.cloudflare.com
ネームサーバー2: tadeo.ns.cloudflare.com

入力欄が3つ以上ある場合、3つ目以降は空欄にする。
既存の ns3.xdomain.ne.jp などが残っていたら削除して空欄にすること。

### 6. 【重要】確定前に報告する
「確認画面へ進む」を押す。

確認画面が表示されたら、**ここで一度停止**し、以下を報告してください:
- 入力したネームサーバーの値（画面に表示されているものを正確に）
- 対象ドメイン名が saunako.jp であること
- 他に変更される項目がないか

私が「確定してよい」と返答するまで、「設定を変更する」ボタンを押さないでください。

### 7. 確定（承認後のみ）
承認を得てから「設定を変更する」を押す。
完了画面のスクリーンショットを撮る。

### 8. 完了後の確認
ネームサーバー設定画面を再度開き、設定が反映されているか確認する。
（この時点では画面上の設定値が変わっていればOK。実際のDNS反映には数時間かかります）

## 報告フォーマット
1. ログインアカウント名
2. ドメイン一覧に表示されていたドメイン
3. 変更前のネームサーバー
4. 変更後のネームサーバー（画面表示のとおり）
5. 完了画面のスクリーンショット
6. 想定外だったこと

## 途中で止めるべきケース
- ログイン・2要素認証を求められた
- ドメイン一覧に saunako.jp が見つからない
- 「その他のサービスで利用する」という選択肢がない
- ネームサーバーの入力欄が2つ未満、または形式が想定と違う
- 料金の支払いや契約更新を求められた
- 確認画面に、ネームサーバー以外の変更項目が含まれていた
```

## 切替後にこちらで検証すること

検証スクリプトを用意済み。

```bash
zsh scripts/verify-dns-switch.sh
```

チェック内容:

- ネームサーバーがCloudflareに切り替わったか
- Aレコードが `216.198.79.1`（Vercel直）のままか
- CNAME www がVercelを向いているか
- **TXT（Search Console所有権）が維持されているか**
- MXが増えていないか
- **Cloudflareプロキシを経由していないか**（IPが104.x等になっていたら設定ミス）

反映には数時間〜24時間かかるため、切替直後は「WAIT まだXserver」と出るのが正常。

### 手動確認（スクリプトでは代替不可）

- ブラウザで https://www.saunako.jp を開く（`curl` はVercel Bot保護で403になるため使えない）
- https://saunako.jp が www へ301リダイレクトされる
- Search Console（`sc-domain:saunako.jp`）にアクセスできる
